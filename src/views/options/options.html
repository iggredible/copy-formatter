Copy Formatter Configuration

Menu Items

Each menu item has a name, a template, and an optional keyboard shortcut. Use {selectedText}, {pageUrl}, and {pageTitle} as placeholders in your templates.

Keyboard Shortcuts

You can now assign a keyboard shortcut to any menu item. With text selected on a page, press the shortcut to copy it in that format without opening the menu.

  1. Click Edit on a menu item, or + Add Menu Item.
  2. Click the Keyboard shortcut field and press the combination you want, for example Ctrl + Option + C. Press Backspace or click Clear to remove it.
  3. Click Save.

A shortcut must include a modifier so it doesn't trigger while you type: Ctrl, Option or Cmd on macOS, and Ctrl or Alt on Windows and Linux. Two menu items can't share the same shortcut.
